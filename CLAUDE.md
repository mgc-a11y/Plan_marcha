# Nutri_bici

## Objetivo
Web para ciclistas que funciona en el navegador, sin servidor:
1. Subo un GPX.
2. Calcula el ritmo según mi FTP y mi peso.
3. Da un plan de hidratos por hora con el valor que yo elija.
4. Genera un archivo para mi Garmin Edge 1030 Plus con los puntos donde comer y beber.

Proyecto de 12 semanas (desde el 23/11/2026). Mi meta es aprender Claude Code y divertirme.
El plan completo está en `Plan de aprendizaje app de nutrición y ritmo para ciclistas.pdf`.

## Stack
- HTML, CSS y JavaScript sin framework.
- Todo se calcula en el navegador. El GPX no sale del dispositivo.
- Publicado en GitHub Pages. Versiones con Git y GitHub.
- Pruebas automáticas con Vitest a partir de la semana 4.
- La web está solo en español.
